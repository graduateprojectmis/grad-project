## 🔐 安全性功能

### 1. Admin API 權限驗證
- [ ] 實作 Admin Token 驗證機制
  - 在 .env 中設定 ADMIN_TOKEN
  - 使用 X-Admin-Token header 進行驗證
  - 支援遠端存取時的權限控制

- [ ] IP 白名單機制
  - 設定允許存取的 IP 範圍
  - 記錄存取日誌
  - 異常 IP 自動封鎖

- [ ] API Rate Limiting
  - 限制每個 IP 的請求頻率
  - 防止 API 濫用
  - 使用 slowapi 或 fastapi-limiter

### 2. API Key 安全管理
- [ ] API Key 加密存儲
  - 使用加密方式存儲 API Key
  - 避免明文存儲在 .env 中

- [ ] API Key 輪換機制
  - 定期提醒更新 API Key
  - 支援多組 API Key 輪流使用

- [ ] 使用量監控
  - 追蹤 OpenAI API 使用量
  - 設定使用上限警告
  - 成本估算功能

## 資料模型

### API 請求/回應模型

```
QuestionRequest                 QuestionResponse
├─ question: str               ├─ question: str
└─ top_k: int = 1             ├─ answer: str
                               ├─ status: str
                               └─ source_chunks: List[str]

SearchRequest                   SearchResponse
├─ query: str                  ├─ query: str
└─ n_results: int = 1         ├─ results: List[str]
                               └─ status: str

HealthResponse
├─ status: str
├─ message: str
├─ chroma_db_count: int
└─ version: str
```

### 資料處理模型

```
DocumentWithEmbedding
├─ title: str
├─ title_embedding: List[float]
└─ chunks: List[DocumentChunk]
    └─ DocumentChunk
        ├─ chunk_text: str
        └─ chunk_embedding: List[float]
```
